# SIG_123140200
Tugas Sistem Informasi Geografis saya
## Deskripsi

Repository ini berisi proyek Sistem Informasi Geografis (SIG) untuk mengelola, menyimpan, dan menampilkan data spasial. Pengolahan dan visualisasi peta menggunakan QGIS, sedangkan pengelolaan database spasial menggunakan PostgreSQL/PostGIS melalui pgAdmin. Proyek ini dibuat untuk mendukung analisis data geografis secara lebih terstruktur dan efisien.
